Роль: Senior UI/UX Engineer (эксперт по микро-взаимодействиям и адаптивной верстке).

Задача: Реализовать динамическое перестроение кнопок действий (карандаш и крестик) в карточке события в зависимости от высоты контента (наличия описания).

Логика работы компонента:

1. HTML-структура карточки:
   Карточка (.event-card) должна иметь класс-модификатор, если у события есть описание (например, .has-description). 
   Кнопки действий (карандаш и крестик) находятся в общем контейнере (.event-actions), который всегда позиционируется абсолютно в правом верхнем углу (top: 12px; right: 12px;).

2. Состояние "Тонкое событие" (БЕЗ описания, класс .has-description отсутствует):
   - Контейнер кнопок (.event-actions) имеет display: flex; flex-direction: row; gap: 8px; (кнопки выстроены горизонтально в ряд).
   - Текстовый блок заголовка (.event-title) имеет padding-right: 76px;, чтобы текст не залезал под горизонтальные кнопки.

3. Состояние "Большое событие" (С описанием, класс .has-description активен):
   - Контейнер кнопок (.event-actions) автоматически переключается на flex-direction: column; gap: 6px; (кнопки выстраиваются вертикально в столбик: крестик сверху, карандаш под ним).
   - Текстовый блок (.event-content) динамически уменьшает свой правый отступ: padding-right: 44px;. Это мгновенно освобождает пространство для текста описания, убирая пустую дыру справа.

4. Индикатор повторения (↻):
   - Должен находиться строго внизу текстового контейнера (.event-content) под описанием. Он позиционируется статически/относительно в потоке документа, чтобы текст описания естественным образом сдвигал его вниз, исключая любые наложения.

5. Эстетика Apple:
   - Все переходы (изменение padding-right у текста, смещение кнопки карандаша сверху-вниз) должны быть анимированы через плавный transition (например, transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)).
   - Кнопки появляются только при hover на карточку (.event-card:hover .event-actions { opacity: 1; pointer-events: auto; }). В обычном состоянии они скрыты (opacity: 0; pointer-events: none;).

Напиши чистый, оптимизированный код на React (с использованием Tailwind CSS или чистого CSS), реализующий эту логику переключения стилей на основе класса .has-description.
