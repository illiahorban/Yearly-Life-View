Роль: Senior Frontend Developer / UI Engineer (эксперт в Apple Design Guidelines).

Задача: Создать компонент карточки события для календаря на React + Tailwind CSS (или чистом HTML/CSS). Компонент должен быть пиксель-перфектным, адаптивным к любому объему контента и следовать строгой эстетике Apple (темная тема).

Главная проблема текущей реализации, которую нужно решить: При наведении элементы управления (редактирование, удаление) накладываются на текст названия/описания, а появление иконок сдвигает контент и ломает верстку.

Технические требования к структуре и позиционированию:

1. Контейнер карточки (.event-card):
   - Относительное позиционирование (position: relative), чтобы внутренние абсолютные элементы выравнивались относительно него.
   - Дисплей: flex, выравнивание по верхнему краю (align-items: flex-start).
   - Минимальная высота (min-height), чтобы карточка выглядела аккуратно даже с ультра-коротким заголовком в одну строчку.
   - Скругление углов (border-radius: 12px), темный полупрозрачный фон в стиле iOS/macOS.

2. Левая часть (Drag-and-Drop ручка):
   - Иконка «шеститочие» (⠿) для перетаскивания.
   - Должна быть выровнена по оптическому центру ПЕРВОЙ строки заголовка (не по центру всей карточки). Дай ей небольшой margin-top (около 2-4px).

3. Центральная часть (Контентный блок):
   - flex-grow: 1, чтобы занимать все свободное пространство.
   - ВАЖНО: жесткий правый отступ (padding-right: 76px). Это «зеленая зона» безопасности. Текст заголовка или описания физически не должен иметь возможности залезть под кнопки управления в правом верхнем углу, он должен переноситься раньше.
   - Заголовок: жирный, контрастный.
   - Описание (если есть): приглушенный серый цвет (системный серый Apple), меньший размер шрифта.

4. Индикатор повторения события (↻):
   - Должен находиться строго ВНИЗУ контентного блока (под описанием), а не сбоку.
   - Отображается всегда (не скрывается).
   - Оформление: приглушенный цвет, иконка круглой стрелочки + текст (например, "Ежегодно"). Можно завернуть в аккуратный микро-баджик с едва заметной подложкой (rgba(255,255,255, 0.05)).

5. Правая часть (Кнопки действий — Карандаш и Крестик):
   - Абсолютное позиционирование (position: absolute; right: 12px; top: 12px).
   - В обычном состоянии скрыты (opacity: 0, pointer-events: none).
   - При наведении на карточку (:hover на .event-card) плавно появляются (opacity: 1, pointer-events: auto) через transition: opacity 0.15s ease-in-out.
   - Появление кнопок не должно вызывать никаких сдвигов текста или изменения размеров карточки (layout shift).
   - Оформление кнопок: круглые, аккуратные. При наведении на крестик — деликатный красный акцент (soft red), при наведении на карандаш — легкое подсвечивание.

Напиши чистый, структурированный код (HTML/CSS или React + Tailwind) с подробными комментариями у ключевых свойств позиционирования.
