This matches a known Chrome mobile rendering quirk where overflow: hidden on a position: absolute; inset: 0 child inside an aspect-ratio grid item can fail to clip during a re-render triggered by state change. The outer tile div is overflow: visible — that's the actual escape hatch.
The fix: overflow: hidden on the outer tile base div itself (a concrete grid item, not absolutely positioned). The only side-effect is the fire-glow box-shadow gets clipped — but I can preserve it by switching the glow to outline (which is never clipped by overflow: hidden).
